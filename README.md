# NITI home page banner options

A mock-up of the NITI Aayog home page slider with 11 proposed banners for the Reform Tracker, shown after NITI's current banner.

- Open `index.html` in any browser, or turn on GitHub Pages (Settings > Pages > Deploy from branch > main, root) to share it as a link.
- Works on desktop and phones. On a phone each banner switches to a stacked layout, and you can swipe between banners.
- One self-contained file: photos are built in; fonts load from Google Fonts.

Mock-up for discussion only. Photos are placeholders from Wikimedia Commons; the PM's official portrait is GODL-India.
